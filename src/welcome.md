# Welcome

Welcome to the Avro Wiki! This is your gateway to a comprehensive knowledge base.

## What is This Wiki?

This wiki is built using [mdBook](https://rust-lang.github.io/mdBook/), a modern documentation tool that creates beautiful, searchable books from markdown files.

## Why mdBook for 15000+ Files?

mdBook is ideal for large-scale wikis because it:

1. **Scales Well**: Handles thousands of markdown files efficiently
2. **Fast Search**: Built-in search indexes all content
3. **Static Output**: Generates fast-loading HTML pages
4. **Git-Friendly**: Plain text markdown files work perfectly with version control
5. **Obsidian Compatible**: Works seamlessly with Obsidian notes

## Quick Start

### For Readers
- Use the **sidebar** on the left to navigate through topics
- Use the **search bar** (🔍) at the top to find specific content
- Click the **edit button** (✏️) on any page to suggest improvements

### For Contributors
- All content is stored as markdown files in the `src/` directory
- Edit files using your favorite text editor or Obsidian
- Commit changes to the git repository
- The wiki rebuilds automatically

## Navigation Tips

- **Expand/Collapse**: Click on category names in the sidebar to show/hide subcategories
- **Keyboard Shortcuts**: 
  - `s` or `/` - Focus search
  - `←` `→` - Navigate between pages
  - `Esc` - Close search/sidebar
- **Mobile Friendly**: The wiki works great on mobile devices
