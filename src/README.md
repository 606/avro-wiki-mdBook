# Welcome to Avro Wiki

This is a comprehensive wiki built with mdBook, designed to handle 15000+ markdown files from Obsidian.

## Overview

This wiki serves as a centralized knowledge base, supporting:

- **Large Scale**: Optimized for 15000+ markdown files
- **Obsidian Compatible**: Seamless integration with Obsidian notes
- **Fast Search**: Powerful search functionality across all pages
- **Easy Navigation**: Hierarchical organization with collapsible sections
- **Version Control**: Git-based with full history

## Features

### Search
Use the search bar (🔍) at the top to quickly find content across all pages.

### Navigation
- Use the sidebar to browse by category
- Click on sections to expand/collapse them
- Use browser's back/forward buttons to navigate history

### Obsidian Integration
This wiki supports common Obsidian features:
- Internal links between notes
- Markdown formatting
- Code blocks with syntax highlighting
- Tables and lists
- Images and attachments

## Getting Started

1. Browse the [Categories](./categories/category-a/README.md) to explore content
2. Use the [Search](./search-tips.md) to find specific topics
3. Check [How to Use](./how-to-use.md) for detailed instructions
