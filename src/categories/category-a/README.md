## Organization

For a large wiki (15000+ files), consider organizing by:
- Subject matter
- Date/time
- Project
- Type of content (tutorials, references, guides)
- Alphabetically

## Adding Content

To add a new page to this category:

1. Create a new `.md` file in `src/categories/category-a/`
2. Add it to `src/SUMMARY.md` under the Category A section
3. Link to it from this page

## Subcategories

For very large categories, consider creating subcategories:

```
category-a/
├── README.md (this file)
├── subcategory-1/
│   ├── README.md
│   └── pages...
└── subcategory-2/
    ├── README.md
    └── pages...
```
